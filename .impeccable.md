# Design Context — Yello CRM

## Product
Contact management CRM (React 19 + Vite frontend, Fastify backend). Handles 10K+ contacts with import (vCard/iCloud/Google), deduplication, cleanup, enrichment, maps, and public contact cards.

## Target audience
Owner-operator today (single power user managing his own contacts); designed to become a product for other individuals/small teams later. Assume a capable, efficiency-minded user.

## Use cases
Fast lookup and editing of contacts; bulk hygiene work (dedupe, cleanup, geocode, enrich); importing from other ecosystems; sharing a public contact card.

## Brand personality
**Clean & utilitarian** — fast, dense, information-first. Reference points: Linear, Things. The interface should get out of the way; density over decoration; restrained color; motion only for state changes.

## Design system
- Tokens: `frontend/src/styles/design-system.css`, prefix `--ds-{category}-{name}` (colors, spacing 4px scale, type scale, radius, shadows, z-index, transitions, component tokens). **All styling must go through tokens** — no hard-coded hex/px in new code.
- Brand color: `#7C3AED` (`--ds-color-primary`; hover `#6D28D9`, dark `#5B21B6`, light `rgba(124,58,237,0.1)`). One purple only — no ad-hoc gradients.
- Typography: Geist (400/500/600/700) via `--ds-font-family`; sizes/weights from `--ds-font-*` / `--ds-weight-*` only.
- Layout: uniform 32px control height (`--ds-control-height`); spacing from `--ds-space-*`.
- Theming: light mode only for now; keep all colors token-routed so a `[data-theme="dark"]` override block stays cheap.

## Component conventions
- Shared primitives live in `frontend/src/components/ui/`: `ConfirmDialog`, `Toast` (+ `useToast`), `LoadingSpinner`, `EmptyState`, `Button`. Use them — never hand-roll dialogs, toasts, spinners, empty states, or button classes.
- Icons: Font Awesome via `components/Icon.tsx` everywhere.
- Page headers via the `setHeaderConfig` outlet contract (`Layout.tsx`); modals must signal `useLayoutModal().setModalOpen` (built into ConfirmDialog).
- CSS lives in stylesheets (`index.css`, `styles/pages.css`) — no `<style>` blocks in TSX, no static inline `style={{}}`.

## Quality bar
Solid & consistent: every view coherent with the system; skip exhaustive micro-polish unless user-facing daily.
